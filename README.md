# 🕯 Velara — Естетичний Telegram-бот Таро та психології стосунків (v2.5 Production)

Сучасний, повністю асинхронний комерційний бот на **Python 3.11+**, **aiogram 3.x**, **PostgreSQL** (`asyncpg`) / **SQLite** (`aiosqlite`) та **AsyncOpenAI** в ніші сучасного Таро, психології стосунків, сумісності та Арканів за датою народження.

---

## ✦ Ключові оновлення версії 2.5:
* **Без фейкових заглушок:** Повністю усунено шаблонні евристичні відповіді. Якщо LLM недоступна — кредит не списується, користувачу виводиться делікатне повідомлення про навантаження, а адміну летить алерт.
* **1 автоматичний ретрай:** При тимчасових мережевих помилках (`APITimeoutError`, `APIConnectionError`, `RateLimitError`) запит автоматично повторюється через 2 секунди.
* **Кэшування Арканів:** Базовий портрет та платний любовний сценарій зберігаються в БД (`arcana_cache`) і при повторному відкритті повертаються миттєво без повторного виклику LLM.
* **Історія розкладів:** Кожен успішний розклад Таро та перевірка сумісності зберігається в `readings_history`. У профілі доступний перегляд останніх 5 розкладів кнопкою `📜 Мої розклади`.
* **Юніт-економіка LLM:** Усі спожиті токени (Input/Output) записуються в `llm_usage` і відображаються у зведеній панелі `/admin` за 24 години та за весь час.
* **Алерти адміну:** Миттєве сповіщення про кожну оплату Stars із зазначенням суми, юзера та UTM-джерела.
* **М'який Retention-дожим:** Фонова задача кожні 10 хвилин знаходить користувачів, які прийшли з реклами 2-24 години тому, не завершили розклад і мають безкоштовний кредит, та надсилає їм одне ненав'язливе нагадування.
* **Безпечна розсилка (`/broadcast`):** Адмін-розсилка через FSM із вибором сегмента (`Усі активні`, `Без оплат`, `Ті, хто платив`), попереднім переглядом, обмеженням швидкості (~20 пов/сек) та авто-позначкою заблокованих.
* **Чесний Healthcheck:** Ендпоінт `/health` робить реальний `SELECT 1` до поточної бази даних (Postgres/SQLite) та повертає `200 OK` або `500`.

---

## 🛠 Технічний стек:
* **Фреймворк:** `aiogram 3.x` (FSM, Роутери, Middleware).
* **База даних:** Dual-Engine адаптер з підтримкою **PostgreSQL** (Render/Supabase через `asyncpg`) та автоматичним fallback на **SQLite** (`aiosqlite`). Повна авто-міграція колонок та таблиць.
* **LLM клієнт:** `AsyncOpenAI` (OpenRouter Claude 3.5 Sonnet, OpenAI GPT-4o, Google Gemini Flash) з `max_tokens=650`, `timeout=30.0` та HTML-санітайзером.
* **Монетизація:** Нативна оплата `Telegram Stars` (`XTR`), динамічне налаштування цін з `.env`, команди `/paysupport` та `/refund`.

```

├── middlewares/

├── prompts/
│   ├── tarot_prompt.py         # Промпт Таро
│   ├── compatibility_prompt.py # Промпт сумісності

├── keyboards/
│   ├── menu.py                 # Меню, профіль, історія розкладів
│   ├── tarot_kb.py             # Сітка вибору карт [ ✦ ], динамічні пейволи
│   └── payment_kb.py           # Інвойси та кнопки Telegram Stars
├── handlers/
│   ├── start.py                # /start, deep-link (utm/ref), історія розкладів

│   ├── payments.py             # Telegram Stars, каталог товарів, миттєвий алерт адміну про оплату
│   └── admin.py                # /admin (воронка + юніт-економіка токенів), /export (CSV), /refund, /broadcast
```

## 🚀 Швидкий запуск:

### 1. Встановлення залежностей:
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### 2. Налаштування `.env`:
```bash
cp .env.example .env
```
Заповніть змінні:
* `BOT_TOKEN` — токен від @BotFather.
* `ADMIN_IDS` — числовий Telegram ID адміністратора.
* `DATABASE_URL` — (опціонально) рядок підключення до PostgreSQL (наприклад, на Render). Якщо порожній — використовується локальний SQLite.
* `LLM_API_KEY` — ключ API (OpenRouter або OpenAI).
* `LLM_MODEL` — рекомендовано `anthropic/claude-3.5-sonnet` (через OpenRouter) або `gpt-4o`.
* `PRICE_TAROT_1`, `PRICE_TAROT_3`, `PRICE_ARCANA_LOVE`, `PRICE_COMPAT` — ціни у Stars.
* `SUPPORT_USERNAME` — юзернейм підтримки.

### 3. Запуск:
```bash
python main.py
```
*(Всі таблиці та міграції створюються автоматично).*
