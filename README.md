# 🔮 Telegram-бот «Астра» (Smoke Test / Заглушка для проверки спроса)

Современный бот на **Python 3**, **aiogram 3.x** и **aiosqlite**, созданный для тестирования спроса и маркетинговой конверсии из **TikTok** (и других источников).

---

## 🚀 Как это работает

1. **Для пользователя (посетителя):**
   - Человек переходит по ссылке из TikTok и жмет `/start`.
   - Видит стильное приветствие в эзотерической тематике и интерактивные кнопки меню (*Экспресс-расклад Таро*, *Совместимость пар*, *Натальная карта* и др.).
   - При нажатии на любую кнопку получает всплывающее системное уведомление о закрытом тестировании и калибровке колод.
   - Пользователь автоматически заносится в базу раннего доступа.

2. **Для вас (аналитика и конверсия):**
   - **Мгновенные уведомления в ЛС:** Бот сразу пишет вам в Telegram: кто зашёл (имя, юзернейм, ID, точное время) и по какой ссылке.
   - **UTM-метки креативов:** Вы видите, какое конкретно видео из TikTok привело человека.
   - **Тест интереса:** Бот уведомляет, на какую кнопку нажал человек (что именно больше всего хотят: Таро, совместимость или гороскоп).
   - **Команда `/stats`:** Прямо в Telegram выводит общую статистику переходов, конверсию по видео и популярность разделов.
   - **Команда `/export`:** Выгружает файл `leads.csv` со всеми контактами для Excel / Google Таблиц.

## 🛠 Быстрый старт

### 1. Настройка переменных окружения
Создайте файл `.env` (скопировав из `.env.example`):
```bash
cp .env.example .env
```
Заполните в файле `.env`:
* `BOT_TOKEN` — токен вашего бота от [@BotFather](https://t.me/BotFather).
* `ADMIN_IDS` — ваш числовой Telegram ID (узнать можно в [@userinfobot](https://t.me/userinfobot)). Можно указать несколько через запятую.

### 2. Запуск локально
```bash
# Активация виртуального окружения
source venv/bin/activate

# Запуск бота
python main.py
```

## 🔗 Как генерировать ссылки для видео в TikTok

Чтобы точно отслеживать, какое видео или ссылка в шапке профиля приносит трафик, используйте параметры `?start=МЕТКА`:

* Ссылка в шапке профиля:  
  `https://t.me/ИМЯ_ВАШЕГО_БОТА?start=tt_bio`
* Видео про Таро (креатив 1):  
  `https://t.me/ИМЯ_ВАШЕГО_БОТА?start=tt_taro1`
* Видео про совместимость знаков:  
  `https://t.me/ИМЯ_ВАШЕГО_БОТА?start=tt_sovmest2`
* Рекламный пост у блогера:  
  `https://t.me/ИМЯ_ВАШЕГО_БОТА?start=pr_blogger1`

Все эти метки бот автоматически привязывает к пользователю и выводит в `/stats`.

## 📱 Админ-команды в боте

* `/stats` — сводная статистика: общее число пользователей, переходы за 24ч, разбивка по TikTok-меткам и востребованность разделов.
* `/export` — скачать файл базы данных в формате `leads.csv` прямо в чат.
* `/help_admin` — краткая памятка по командам и созданию ссылок.

## ☁️ Развёртывание на бесплатном сервере

### Вариант 1: Koyeb (Рекомендуется, бесплатно 24/7)
1. Зарегистрируйтесь на [koyeb.com](https://www.koyeb.com).
2. Загрузите этот репозиторий на свой GitHub.
3. В Koyeb нажмите **Create App** -> выберите GitHub репозиторий.
4. В разделе **Environment Variables** добавьте `BOT_TOKEN` и `ADMIN_IDS`.
5. Нажмите **Deploy**. Бот будет работать круглосуточно.

### Вариант 2: Render.com
1. Зарегистрируйтесь на [render.com](https://render.com).
2. Создайте новый **Background Worker** (или привяжите репозиторий через `render.yaml`).
3. Задайте переменные окружения `BOT_TOKEN` и `ADMIN_IDS`.

### Вариант 3: Docker
```bash
docker build -t gadalka-bot .
docker run -d --name gadalka-bot --env-file .env gadalka-bot
```
